# 인플루언서 점수 판단 로직

유튜브 데이터 기반으로 인플루언서의 신뢰도 점수를 계산하고, 인스타그램 연동 시 가점을 부여합니다.

### 기본 점수: 0점 (합산 방식)

---

## 유튜브 기반 점수 (최대 95점)

### 1. 구독자 수 (0~30점)
```
점수 = log10(구독자) × 5 (최대 30점)
```
| 구독자 수 | 점수 |
|-----------|------|
| 1,000명 | 15점 |
| 10,000명 | 20점 |
| 100,000명 | 25점 |
| 1,000,000명 | 30점 |

### 2. 조회율 (0~20점)
```
조회율 = (평균 조회수 / 구독자 수) × 100
```
| 조회율 | 점수 |
|--------|------|
| > 50% | 20점 |
| > 20% | 15점 |
| > 10% | 10점 |
| > 5% | 5점 |

### 3. 인게이지먼트 (0~15점)
```
인게이지먼트 = (평균 좋아요 / 평균 조회수) × 100
```
| 인게이지먼트 | 점수 |
|--------------|------|
| > 5% | 15점 |
| > 3% | 10점 |
| > 1% | 5점 |

### 4. 영상 개수 (0~10점)
| 영상 수 | 점수 |
|---------|------|
| ≥ 20개 | 10점 |
| ≥ 10개 | 7점 |
| ≥ 5개 | 5점 |
| ≥ 3개 | 3점 |

### 5. 뷰티/헤어 도메인 (+20 / -30점)
**키워드 매칭 대상:**
- 채널 설명 (description)
- 채널 제목 (title)

**키워드 목록:**
```
헤어, 펌, 염색, 컷, 미용, 살롱, 두피, 탈모,
메이크업, 뷰티, 스타일링, 샴푸, 트리트먼트,
hair, beauty, makeup, salon, styling,
디자이너, 원장, 고데기, 드라이, 컬러
```

| 조건 | 점수 |
|------|------|
| 키워드 포함 | +20점 |
| 키워드 없음 | -30점 |
