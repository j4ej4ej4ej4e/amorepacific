# Ground Truth 점진적 확장 워크플로우

## 🎯 목표
44개 → 100개 → 200개로 점진적으로 Ground Truth를 확장하여  
더 정확한 Threshold를 도출

## 📅 4주 계획

### Week 1: 초기 프로토타입 (✅ 완료)
```bash
# 1. 초기 44개로 최적화
python optimize_threshold.py

# 결과:
# - Threshold: 0.52
# - F1: 0.909
# - ROC-AUC: 0.91
```

### Week 2: 첫 번째 확장 (44 → 94개)
```bash
# 1. 파이프라인 실행 (초기 threshold 사용)
python main.py --depth 3 --limit 200

# 2. 상위 50개 키워드 추출
# output/keyword_tree_YYYYMMDD_keywords.txt 파일 생성됨

# 3. 대화형 라벨링 (50개 중 일부)
python expand_ground_truth.py \
    --keywords output/keyword_tree_YYYYMMDD_keywords.txt \
    --batch 25

# 예상 소요: 10-15분

# 4. 재최적화
python expand_ground_truth.py --optimize

# 예상 결과:
# - 데이터: 69개 (44 + 25)
# - Threshold: 0.51 ± 0.02
# - F1: 0.912 ~ 0.918
```

### Week 3: 두 번째 확장 (94 → 144개)
```bash
# 1. 업데이트된 threshold로 재실행
# hair_embedder.py 수정 후
python main.py --depth 3 --limit 200

    --batch 50 \

# 예상 결과:
# - 데이터: 144개
# - Threshold: 0.52 (안정화)
# - F1: 0.915 ~ 0.920
```

### Week 4: 검증 및 마무리

## 💡 실전 팁

### 라벨링 시 기준

✅ **헤어 관련**
- 스타일: 허쉬컷, 볼륨펌, 레이어드컷
- 시술: 염색, 탈색, 펌, 매직
- 제품: 샴푸, 트리트먼트, 헤어오일
- 케어: 두피 케어, 손상모 관리
- 상태: 볼륨감, 윤기, 찰랑

❌ **비관련**
- 메이크업: 립스틱, 파운데이션
- 스킨케어: 수분 크림, 토너
- 패션: 코디, 악세서리
- 라이프: 일상, 브이로그

⚠️ **애매한 경우**
```
"볼륨감" → 헤어 볼륨? 메이크업 볼륨?
→ 유사도를 참고하되, 도메인 지식 활용
→ 헤어가 더 일반적이면 y
```

### 효율적 라벨링

1. **배치 크기**: 20-30개 (집중력 유지)
2. **휴식**: 30개마다 5분 휴식
3. **일관성**: 같은 날 라벨링 (기준 일관성)
4. **메모**: 애매한 경우 note에 이유 기록

## 🎯 성공 기준

### 데이터 품질
- ✅ 최소 100개 이상
- ✅ Positive:Negative = 5:5 ~ 6:4
- ✅ 경계 사례 20% 포함

### 성능 지표
- ✅ ROC-AUC ≥ 0.90
- ✅ F1-Score ≥ 0.90
- ✅ Precision ≥ 85%
- ✅ Recall ≥ 90%

### 안정성
- ✅ Threshold 변동 < 0.05
- ✅ 연속 2회 최적화 결과 일치

## 🚨 문제 해결

### "데이터가 부족합니다"
```bash
# 최소 20개 필요
python expand_ground_truth.py --stats
# → 현재 개수 확인 후 더 라벨링
```

### "파일 없음"
```bash
# main.py 실행하여 키워드 파일 생성
python main.py --limit 100

# 생성된 파일 경로 확인
ls output/
```

### Threshold가 크게 변동
```
원인: 데이터 편향 or 샘플 부족
해결: 
1. 균형 잡힌 라벨링 (Positive:Negative)
2. 경계 사례 추가
3. 샘플 수 증가
```
